# Программа и методика испытаний информационной системы магазина настольных игр

Колледж ВятГУ · Магомедов Е. С. · ИСПк-302-52-00 · Киров · 2026

## Объект и цель испытаний

Объект испытаний — настольное приложение магазина настольных игр и его база PostgreSQL. Проверяется соответствие функций, прав, интерфейса, расчётов и поведения при ошибках требованиям ТЗ.

## Условия и подготовка

1. Подготовить ПК с Windows или Linux, Python 3.11+, PostgreSQL, приложением и библиотеками из `requirements.txt`. Зафиксировать фактические версии в протоколе.
2. Использовать отдельную базу с учебными данными. Для автоматического набора указать базу с именем, оканчивающимся на `_test`. Создать схему и загрузить демонстрационный каталог.
3. Зарегистрировать двух клиентов. Создать работника и администратора с разными адресами. Использовать вымышленные контактные данные. Подготовить товар с остатком 1, заказ в обработке и папку для чека.
4. Поместить `DejaVuSans.ttf` в `assets/fonts/` и подготовить два образца изображения допустимого и недопустимого размера.

Провести один сквозной прогон по ролям, затем проверить негативные сценарии на том же наборе данных. Для каждого пункта записать результат и отметку. После устранения дефекта повторить затронутый сценарий.

## Завершение испытаний

Испытания считаются успешными после выполнения проверок и устранения критических дефектов. Приёмка и оформление акта выполняются комиссией в порядке, предусмотренном ТЗ.
