# Руководство пользователя информационной системы магазина настольных игр

Колледж ВятГУ · Магомедов Е. С. · ИСПк-302-52-00 · Киров · 2026

## Назначение и запуск

В системе можно выбрать настольную игру и заказать её для получения в магазине. Работники обрабатывают заказы и обновляют данные магазина. Администратор управляет учётными записями.

Требования к компьютеру: процессор от 2 ГГц, 4 ГБ ОЗУ, 2 ГБ свободного места. Для работы нужны Python 3.11+ и PostgreSQL. На подготовленном компьютере с Windows откройте `start.cmd`. Первоначальная установка и настройка описаны в [README](../README.md).

## Вход и регистрация

На экране входа введите электронную почту и пароль. Если учётной записи ещё нет, нажмите **Нет аккаунта? Зарегистрироваться**. Введите почту и пароль дважды, подтвердите согласие на обработку персональных данных и завершите регистрацию. Для входа работника используйте данные, выданные администратором.

## Покупатель

1. Откройте **Главная**, чтобы увидеть популярные игры. Нажмите **Перейти в каталог** для просмотра ассортимента.
2. В **Каталоге** введите часть названия или описания. При необходимости укажите жанр, число игроков, длительность партии и возраст. Фильтры применяются одновременно.
3. Нажмите **Открыть карточку**, чтобы увидеть описание, цену и характеристики. Укажите количество и нажмите **Добавить в корзину**. Игру без остатка можно добавить в избранное.
4. Откройте **Избранное** для просмотра сохранённых игр. Кнопка **Убрать из избранного** удаляет отметку.
5. В разделе **Корзина** при необходимости измените количество и нажмите **Сохранить** в строке игры. Проверьте итог, затем нажмите **Заказать**. Заказ забирают в магазине.
6. Нажмите кнопку с именем на левой панели, чтобы открыть профиль. Можно изменить имя, телефон, аватар и тему. Настройка темы применяется при выборе, поля профиля сохраняются по кнопке **Сохранить профиль**.
7. В профиле нажмите **Мои заказы**. Используйте **Скачать чек**, выберите папку и подтвердите сохранение. Кнопка **Удалить** доступна для заказа со статусом **Новый**. Его товары возвращаются на склад.

## Работник

- **Товары.** Найдите игру по названию или через фильтры категории и цены. Нажмите **Добавить товар** или **Изменить**. Введите название, категорию, цену, остаток, диапазон игроков, длительность партии и возраст. Добавьте описание и при необходимости фото, затем сохраните. Если товар входит в заказ, установите остаток 0, чтобы снять его с продажи.
- **Заказы.** Вкладки показывают заказы по статусу. Поиск работает по номеру, имени, почте и названию товара. Чтобы создать заказ, нажмите **Добавить заказ**, выберите клиента и внесите товары с количеством. Состав можно изменить, пока заказ новый. Статус двигается последовательно от **Новый** к **В обработке** и **Доставленный**. Последний статус означает выдачу в магазине. Чек скачивается для любого заказа.
- **Поставщики.** Найдите поставщика по названию либо статусу. В форме добавления или изменения укажите название, почту, телефон, статус и отметьте его товары.
- **Профиль.** Кнопка с именем открывает личные настройки, роль и список прав.

## Администратор

В разделе **Пользователи** можно искать записи по имени и почте, фильтровать по роли и статусу, добавлять сотрудников, редактировать данные и блокировать пользователей. При изменении учётной записи заполните поле пароля, только если нужно его сменить. У пользователя с заказами доступна блокировка. Для своей записи администратор сохраняет активный статус и роль администратора.

## Сообщения и действия

| Сообщение | Причина | Что сделать |
|---|---|---|
| Неверная электронная почта или пароль | Ошибка во входных данных или такой записи нет | Проверьте адрес, раскладку и пароль |
| Учётная запись заблокирована | Доступ отключён администратором | Свяжитесь с администратором |
| Недостаточно товара | Остаток изменился с момента добавления в корзину | Обновите корзину, уменьшите количество и повторите заказ |
| Не найден шрифт для чека | Файл DejaVuSans.ttf отсутствует | Поместите файл в папку assets/fonts |
| Не удалось сохранить чек | Нет доступа к папке или свободного места | Выберите папку, доступную для записи |
| Не удалось выполнить операцию с базой данных | Соединение с PostgreSQL недоступно или запрос завершился ошибкой | Проверьте, запущен ли PostgreSQL, и повторите операцию |
