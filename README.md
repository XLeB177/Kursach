# Информационная система для магазина настольных игр

Десктопное приложение для одного магазина. Покупатель подбирает игру и оформляет заказ с самовывозом. Работник ведёт товары, заказы и поставщиков. Администратор дополнительно управляет учётными записями.

## Системные требования

Windows или Linux, Python 3.11+, PostgreSQL, процессор от 2 ГГц, 4 ГБ ОЗУ и 2 ГБ свободного места. Интерфейс работает на PyQt6, подключение к PostgreSQL выполняет psycopg2, PDF формирует ReportLab.

## Запуск на Windows

Если папки `.venv` и `.postgres` уже подготовлены, откройте `start.cmd`. Он запустит PostgreSQL проекта при необходимости и откроет окно входа. Клиент регистрируется в приложении самостоятельно.

При установке с нуля установите PostgreSQL, затем выполните в PowerShell из папки проекта:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m scripts.local_postgres prepare
.\start.cmd
```

Локальная база получает демонстрационный каталог и работает на `127.0.0.1:55473`. Настройки и сгенерированный пароль подключения хранятся в `.env`, данные PostgreSQL — в `.postgres`. При нестандартной установке укажите папку `bin` параметром `--bin`. Для остановки локального PostgreSQL закройте приложение и выполните `.\.venv\Scripts\python.exe -m scripts.local_postgres stop`.

### Подключение к уже установленному серверу

Создайте пустую базу `board_games` в PostgreSQL с UTF-8 и локалью, поддерживающей обработку кириллицы. Скопируйте `.env.example` в `.env` и внесите реквизиты подключения. Активируйте виртуальное окружение или укажите его Python в командах:

```text
python -m scripts.setup_db --demo
python main.py
```

Флаг `--demo` загружает учебные игры, категории и поставщиков. Для пустой схемы запустите настройку без этого флага. Этот же способ подходит для Linux.

### Первый работник и администратор

Запустите `python -m scripts.create_admin admin@example.test "Администратор"` из папки проекта тем же Python. Скрипт запросит пароль и подтверждение. В рабочем приложении администратор добавляет сотрудников через **Пользователи → Добавить пользователя**. Для демонстрации можно сначала создать работника тем же скриптом с флагом `--role employee`.

### PDF и изображения

Для чеков положите файл `DejaVuSans.ttf` в `assets/fonts/`. [Официальная страница DejaVu Fonts](https://dejavu-fonts.github.io/Download.html).

Собственный логотип можно положить в `assets/logo.png`. Фото игр добавляются в карточках товаров, аватар — в профиле. При отсутствии изображений приложение показывает заглушки.

## Проверки

Создайте отдельную пустую базу `board_games_test` для автоматических проверок. Она использует параметры подключения из `.env`. Тесты очищают таблицы только в базе, чьё имя оканчивается на `_test`.

```text
python -m pytest -q
```

Только валидаторы можно проверить без PostgreSQL командой `python -m pytest -q tests/test_validators.py`.
