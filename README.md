# Информационная система для магазина настольных игр

Десктопное приложение на Python, PyQt6 и PostgreSQL. Курсовой проект колледжа ВятГУ.

## Стек

- Python 3.11+
- PyQt6
- PostgreSQL (`psycopg2-binary`)
- pytest

## Быстрый старт

1. Создайте виртуальное окружение и установите зависимости:

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

2. Скопируйте `.env.example` в `.env` и укажите параметры PostgreSQL.

Полная инструкция по развёртыванию будет в финальном этапе.
